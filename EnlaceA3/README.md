# Enlace contable a3

Guía de instalación y uso: **[INSTALACION.md](INSTALACION.md)**

| Carpeta | Contenido |
|---|---|
| `dist/` | Ficheros listos para importar en Excel (Windows-1252 + CRLF). **Descarga esta carpeta.** |
| `src/` | Código fuente (UTF-8) del que se genera `dist/` con `python3 tools/build_dist.py` |
| `tests/` | Pruebas que ejecutan el núcleo VBA en LibreOffice (`python3 tests/run_all.py`) |
| `recursos/` | Logo de ACP |
